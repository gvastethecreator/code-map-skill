# Skills

This repository ships one portable Agent Skills package:

- [maintain-code-map](./maintain-code-map/SKILL.md): generate or refresh an evidence-backed repository code map and lock.

The standalone repository is the canonical source. Install with:

```powershell
npx skills add gvastethecreator/code-map-skill --skill maintain-code-map
```

Or copy the package into the skill directory supported by your host.
