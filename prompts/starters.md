# Starter prompts

Use `$maintain-code-map` when the map is missing, stale, or about to change.

```text
The code map looks stale. Refresh docs/codemap from the current repository and report unknown edges.
```

```text
Create the first code map for this repository. Do not edit product code. Publish json, md, html, and lock together.
```

```text
Before changing the auth module, use the code map to list callers, callees, and covering tests.
```

```text
Module boundaries changed. Update the code map artifacts in the same change set.
```
