# Security policy

Maintain Code Map is an instruction package plus local Python and Node scripts. It does not run a network service. The scripts read a Git working tree you point them at and write under `docs/codemap/` in that tree.

Report a suspected vulnerability privately through [GitHub security advisories](https://github.com/gvastethecreator/code-map-skill/security/advisories/new). Do not include secrets, private prompts, customer artifacts, or exploit details in a public issue.

Supported security fixes target the current `main` branch.
